# LinkedIn Highlights (Copy/Paste)

Built a two-node STM32 Bluetooth robotics system for ENEL-300:

- **Controller node** reads dual-joystick ADC input and streams real-time control packets.
- **Car node** executes motor + servo control with a packet timeout failsafe.
- **Ultrasonic sensing** runs on timer input capture, then publishes live distance telemetry back to the controller LCD.
- Designed a simple, robust serial protocol (`C,...` and `D:...`) for low-latency control + feedback.
- Refactored firmware for production-style readability and maintainability (clean loops, timing constants, sectioned code).
